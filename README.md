# 🎓 CommitteeHub — Academic Committee Management Portal

A centralized, full-stack web platform designed to streamline the management of college committees, clubs, and student organizations.

CampusHub replaces the fragmented ecosystem of WhatsApp groups, spreadsheets, emails, and paper notices with a single role-based platform where students, committee heads, faculty advisors, and administrators can collaborate efficiently.

The platform helps students discover committees that match their interests, enables committee heads to manage announcements and memberships, and provides administrators with analytics-driven insights for creating new committees based on actual student demand.

> Developed as a B.Tech Mini Project for the Department of Computer Science & Engineering, Shri Ram Murti Smarak College of Engineering & Technology (SRMSCET), Bareilly.

---

## 🚀 Key Highlights

* Centralized committee and club management
* Role-based access control (RBAC)
* Student onboarding and personalized recommendations
* Committee membership request workflow
* Notice, event, and achievement management
* Interest-gap analytics for data-driven committee formation
* RESTful API architecture
* JWT-based secure authentication

---

## 📌 Problem Statement

Most college committees operate using disconnected tools such as:

* WhatsApp groups
* Spreadsheets
* Emails
* Notice boards
* Physical records

This often leads to:

* Difficulty for freshers to discover relevant committees
* Missed notices and event updates
* Poor record management
* Manual member tracking
* Lack of insights into student interests

CampusHub addresses these challenges through a unified digital platform that improves communication, transparency, and administrative efficiency.

# ✨ Features

## 👨‍🎓 For Students & Freshers

* Browse a searchable directory of committees and clubs
* Complete an onboarding survey based on interests and skills
* Receive personalized committee recommendations
* Request membership directly from committee profiles
* View notices, announcements, and event updates
* Explore committee achievements through the Hall of Fame

---

## 👨‍💼 For Committee Heads

* Create and publish notices
* Post event announcements and updates
* Review and manage join requests
* Record winners and achievements
* Manage committee engagement

---

## 👨‍🏫 For Faculty Advisors & Administrators

* Create and manage committees
* Assign committee heads
* Monitor membership requests
* View platform-wide analytics
* Identify demand for new committees using interest-gap analysis

---

## 🧠 Recommendation Engine

CampusHub uses a transparent tag-matching recommendation system instead of black-box machine learning models.

Recommendations are generated by matching:

* Student interests
* Skills
* Committee tags
* Activity categories

This ensures explainable and easily interpretable results.

# ⚙️ Getting Started

## Prerequisites

* Node.js 18+
* MongoDB Atlas Account (Recommended)

---

## 1️⃣ Backend Setup

```bash
cd backend

npm install

cp .env.example .env
```

Configure the `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
JWT_EXPIRES_IN=7d
CLIENT_URL=http://localhost:5173
```

Seed demo data and start the backend:

```bash
npm run seed
npm run dev
```

Backend URL:

```text
http://localhost:5000
```

Health Check:

```http
GET /api/health
```

---

## 2️⃣ Frontend Setup

Open a new terminal:

```bash
cd frontend

npm install

npm run dev
```

Frontend URL:

```text
http://localhost:5173
```

# 🔌 API Overview

| Endpoint                          | Description                         |
| --------------------------------- | ----------------------------------- |
| `POST /api/auth/register`         | Register user                       |
| `POST /api/auth/login`            | Authenticate user                   |
| `PUT /api/users/onboarding`       | Submit interests and skills         |
| `GET /api/committees`             | View committees and recommendations |
| `POST /api/join-requests`         | Request committee membership        |
| `GET /api/notices`                | Fetch notices                       |
| `GET /api/events`                 | Fetch events                        |
| `GET /api/winners`                | Fetch achievements                  |
| `GET /api/analytics/interest-gap` | Analytics dashboard                 |
